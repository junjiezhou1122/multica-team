# Contributing

Describe the concrete behavior to improve and its evidence. Keep plugin procedures general. Instance IDs, real local paths, and company-specific grants belong outside this repository.

Run `python3 scripts/check.py` before submitting. Changes to operational behavior need scenarios that distinguish correct and incorrect decisions. Structural validation does not evaluate agent behavior; report whether a live evaluation was performed and its authorization.

Preserve the Agent Memory Repo attribution and MIT notice for adapted material. Proposed changes to the agreed memory format should document compatibility. Use an isolated branch, inspect the diff, and submit a reviewable PR. Do not merge or publish releases as part of a feedback task.
