# Company operations

Company operations are part of the single `multica-team` plugin. Invoke `/multica-team:mops` to operate an existing company or discuss a new one. [Local company discovery](LOCAL_COMPANIES.md) respects explicit targets before defaults and reads machine-local registrations only on invocation.

The 19 operations skills live in [root skills](../skills); supporting documents, templates, and scripts live here. The original operations hooks live in [root hooks](../hooks). [Company knowledge](COMPANY_KNOWLEDGE.md) connects optional memory lookup, decision drafts, owner observations, and retrospective candidates to the four memory skills in the same package. Company records, credentials, and registrations remain outside the package.

Read [installation](INSTALL.md) for the single plugin route and worker attachment limits, [maintenance](MAINTENANCE.md) for provenance and validation, and [commands](COMMANDS.md) for operations commands.
